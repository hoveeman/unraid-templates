# Unraid Community Applications Templates

This repository contains Unraid Community Applications templates maintained by [@hoveeman](https://github.com/hoveeman).

## Available Applications

| Application | Description | Registry | Template |
| :--- | :--- | :--- | :--- |
| **[Antigravity CLI](https://github.com/hoveeman/antigravity-cli-docker)** | Autonomous AI coding agent designed by Google DeepMind running headlessly on Unraid. | [Docker Hub](https://hub.docker.com/r/hovee/antigravity-cli) | [XML](templates/antigravity-cli.xml) |
| **[DVDCompress](https://github.com/hoveeman/DVDCompress)** | Hardware-accelerated authoring and burning for DVD-Video and Blu-ray discs/ISOs. | [Docker Hub](https://hub.docker.com/r/hovee/dvdcompress) | [XML](templates/DVDCompress.xml) |

---

## Adding this Repository to Unraid Manually

If you want to add these templates manually before they appear in the Community Applications catalog:

1. In the Unraid WebGUI, navigate to the **Docker** tab.
2. Under **Template Repositories**, add:
   ```text
   https://github.com/hoveeman/unraid-templates
   ```
3. Click **Save**.
